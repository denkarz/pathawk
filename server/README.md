# postman-server (бэкенд)

Документация продукта (PRD, ТЗ): при мета-репозитории — [../docs/README.md](../docs/README.md).

API синхронизации, шаринг коллекций, SSO/OAuth, аудит, PostgreSQL.

- **Отдельный git-репозиторий:** `git init` в этой директории, свой `origin`.
- Сборка: `go build -o bin/api ./cmd/api`
- OpenAPI / контракты с клиентами: хранить в этом репо (например `api/`) или в общей документации продукта.
