# pathawk-web (фронт)

**Vue 3** — общий UI для браузера и встраивания в **pathawk-desktop** (Electron).

- Локальная разработка: `npm install && npm run dev`
- Связь с десктопом: клон [pathawk/desktop](https://gitlab.com/pathawk/desktop) рядом (`../desktop`); `npm run dev` в desktop поднимает Vite из `../web`.
