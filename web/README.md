# pathawk-web (фронт)

Документация продукта: при мета-репозитории — [../docs/README.md](../docs/README.md).

**Vue 3** — общий UI для браузера и встраивания в **pathawk-desktop** (Electron).

- **Отдельный git-репозиторий:** `git init` в этой папке (`web/`).
- Локальная разработка: `npm install && npm run dev`
- Связь с десктопом: в репо **pathawk-desktop** — `"pathawk-web": "file:../web"` (соседние клоны) или git URL / npm registry.
